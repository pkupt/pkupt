# Kevin Zhang

Maintainer at [Semantica](https://github.com/semantica-agi/semantica), a graph-native context and accountability layer for AI systems (13.9k stars, MIT).

I work on the ontology lifecycle and the knowledge graph layer:

- Ontology and SHACL: bootstrapping domain schemas from extracted data, the draft/proposal/version flow, SHACL constraint generation and validation
- Provenance: W3C PROV-O wrappers
- Knowledge graph analytics: PageRank and label propagation on the context graph
- MCP server: semantic retrieval tools
